# Solutions

Attempt each exercise before reading its solution. These files show one small,
defensible fix; they are not the only valid implementations.

Run from the `interview-prep` directory:

```bash
python solutions/01_data_pipeline.py
python solutions/02_split.py
python solutions/03_dataloader.py
python solutions/04_device.py
python solutions/05_embeddings.py
python solutions/06_training_loop.py
```
